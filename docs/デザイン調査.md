## UIの共通化

- 色の役割は `.streamlit/config.toml`（公式テーマ）で定義
- ヒーローと「利用の流れ」の色は `definereq/ui/theme.py` の `PALETTE` で一元管理。図形はCSS変数を読めないため、ここから図形とCSS変数の両方へ流し込む
- 「利用の流れ」はオレンジ→コーラル→ピンク→マゼンタ→ネオン紫。淡い背景は同じ色から計算し、番号は読める濃さの同系色にする（コントラスト4.5以上）
- 状態は色と文字の両方で表示（`definereq/ui/components.py`）
- CSSは独自部品に限定し、標準部品のフォントは上書きしない（アイコンを壊さないため）
- SVG は `st.html` で除去されるため、CSS の背景画像として埋め込む（実ブラウザの確認で判明）
- 架空の導入社数、効果、推薦は掲載しない
