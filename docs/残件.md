## 機能の制限

| 項目 | 内容 | 判断 |
|---|---|---|
| PDF出力 | 未対応。Wordで開いてPDF保存を案内 | 指示書で許容 |
| 文字起こしモデルの移行 | 現行モデルは 2027-02-26 に提供終了予定。`gpt-transcribe` で時刻付き区間が取れるか未確認 | 提供終了前に要確認。環境変数で変更可能 |
| 容量・帯域の計算 | 計算機能は未実装。人が値と根拠を登録する | 断定を避けるため対象外。必要なら追加 |
| 「なぜこの仕様か」のAI回答 | 未実装。登録情報からプログラムで回答 | 創作を防ぐため。指示書の回答項目は満たす |
| 文書の下書きのAI作成 | 未実装。文書はプログラムが登録情報から組み立てる | 根拠のない文章を防ぐため |
| 録画の映像理解、OCR | 未対応 | 指示書で対象外 |
| 案件の外部保存、複数人編集 | 未対応 | 指示書で対象外 |
| 他作品との直接連携 | 未対応。要件ID付きのJSON・Excelのみ | 指示書で対象外 |
| 責任分界 | 専用の表はなく、要件・影響の領域・未決の領域で管理 | 改善余地 |
| スマートフォンでの編集 | 表の編集は操作しにくい | PCを推奨 |
