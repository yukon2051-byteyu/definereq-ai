# 画面遷移の一覧

`scripts/flow_inventory.py` で、実際の画面を描画して作成した一覧です（手で書き換えないでください）。AIは呼んでいません。
主操作は、その状態で強調表示されるボタンです。「→」の付いた主操作は、押したときの移動先を記録しています。
