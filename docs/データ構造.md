# データ構造

案件は1つのJSONです（`format_version: 1`）。定義は `definereq/schema.py` にあります。

## 全体

| 項目 | 内容 |
|---|---|
| `app`, `format_version` | 形式の識別 |
| `id`, `name`, `domains`, `traits` | 案件の基本 |
| `profile` | 案件情報。各項目は `{value, certainty}` |
| `prep` | 現時点の理解、不足情報、議題など |
| `nfr_status` | 非機能の確認状況 |
| `is_demo`, `demo` | デモの情報 |
| `activity` | 操作の記録 |
| `seq` | ID採番の管理 |

## 一覧

| 一覧 | ID | 内容 |
|---|---|---|
| `stakeholders` | STK | 関係者 |
| `glossary` | TRM | 用語 |
| `sources` | SRC | 資料（版、位置付きの単位、警告、補足） |
| `recordings` | REC | 録画と発言区間 |
| `questions` | QST | 質問と回答 |
| `candidates` | CAN | AI候補と採否 |
| `requirements` | REQ | 要件（`versions` に旧版を保持） |
| `issues` | ISU | 意見調整 |
| `scenarios` | SCN | シナリオ |
| `decisions` | DEC | 判断と合意 |
| `changes` | CHG | 追加要望と影響 |
| `conflicts` | CNF | 矛盾候補 |
| `risks` | RSK | リスク |
| `actions` | ACT | 次の行動 |

## 要点

**未設定と該当なし：** `None` は未設定、`"__該当なし__"` は該当なしです。

**根拠：**

```json
{"source_id": "SRC-001", "unit_id": "U0003", "version": 1, "quote": "引用", "locator": "p.3", "verified": true}
```

**数値条件：**

```json
{"metric": "目標復旧時間（RTO）", "value": 4, "unit": "時間以内", "kind": "必要条件",
 "condition": "基盤障害時", "basis": "第2回打ち合わせ", "status": "確認待ち"}
```

`kind` は 必要条件／現状の計測値／仮定・見積もり／実現方式の候補／人が確定した設計制約 のいずれかです。

**履歴：** `meeting_date`、`proposed_on`、`decided_on`、`applied_on`、`recorded_at` を分けます。不明な日付は `null` のままです。訂正は `corrects` で元の履歴を指す新しい行を追加します。

**読込の検証：** 形式版、一覧の有無、重複ID、ID形式、状態の値、要件間の参照、根拠の資料を確認します。

元ファイルのバイナリは含みません。録画は名称、時刻、文字起こしのみです。

他作品との連携に備え、要件IDはJSON・Excelに出力しています（直接連携は未実装）。
