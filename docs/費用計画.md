予算のために品質を下げる必要が出た場合は、下げずに内容と差額を相談します。

料金は 2026-11-05 に公式ページで確認しました。アプリの試算は請求額を保証しません。

## 仕組み

1. 実行前に対象、送信先、費用見込み、残枠を表示する
2. 人がボタンを押す
3. 見積の上限額で枠を予約する。予約中も枠を消費するので、同時に実行しても上限を超えない
4. 実行後に実績で精算する
5. 失敗時：課金の可能性がなければ0円で閉じ、あれば予約額のまま残す

同じ入力の結果があれば再実行せず、同じ録画・同じ区間の文字起こしは再利用します。

利用記録は本文を含まず、アクセスコードはハッシュで保存します。利用記録に接続できない場合、有料処理は停止します。無料機能には影響しません。

提供元の管理画面でも月額上限の設定を推奨します（Claude Console、OpenAI）。

## 文字起こしの方式

| 観点 | OpenAI gpt-4o-transcribe-diarize【公開環境の第一候補】 | ローカル faster-whisper |
|---|---|---|
| 話者 | ラベルあり（確定は人） | なし |
| 時刻 | 区間ごと | 区間ごと |
| 費用 | $0.006/分 | 0円 |
| 送信先 | OpenAI | なし |
| 実測 | 公開環境で61秒の動画に約23秒 | 開発PCで61.5秒の動画に89.5秒、最大634MB |
| 公開環境 | 実行できることを確認 | 無料CPUでは時間がかかり、モデル約480MBの配置が必要なため標準では未導入 |

**注意：** OpenAI の公式文書では `whisper-1` と `gpt-4o-transcribe-diarize` は非推奨で、2027-02-26 に提供終了予定です。推奨の `gpt-transcribe` は時刻付きの区間が取得できるか公式文書で確認できませんでした。そのためモデル名は環境変数で変更でき、方式は差し替えられる構成にしています。提供終了前に移行先の確認が必要です（[残件](残件.md)）。
