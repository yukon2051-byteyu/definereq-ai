### 不具合の調査：保存して移動するボタンの1回目のクリックが効かない

公開版で、本人が「保存して資料・議事録を取り込む」を押しても画面が変わらず、もう一度押すと移動したことが1回ありました。手元で条件を変えて再現を試しました（Edge ヘッドレス、各条件3回）。

| 条件 | 修正前 | 修正後 |
|---|---|---|
| 未保存の変更がある状態から、0.3秒かけて押す | 3回とも成功 | 未計測 |
| 保存済みの状態から編集し、0.6秒かけて押す | 3回とも失敗 | 3回とも成功 |
| 保存済みの状態から編集し、通信を0.3秒遅らせ、0.3秒かけて押す | 3回中1回失敗 | 3回とも成功 |

- **原因：**
  - 入力欄にカーソルがある状態でボタンを押すと、押した瞬間に入力欄の内容が確定し、画面が再描画されます。
  - このとき、ボタンの上に「保存していない変更があります」の警告が新しく表示されました。ボタンは68px下へずれ（431px → 499px）、部品も作り直されました。
  - そのため、ボタンでは「押した」動作だけが記録され、「離した」「クリック」が記録されませんでした。
- **修正：** ボタンより上に、入力中に表示が変わる部品を置かないようにしました（警告はボタンの下へ移動）。
- **補足：** 最初の再現の試みでは、確認スクリプトがボタンを画面内までスクロールせずに押していたため、結果が無効でした。その結果は記録から除いています。
