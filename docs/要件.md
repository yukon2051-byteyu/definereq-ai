## 目的と対象

| 項目 | 内容 |
|---|---|
| 目的 | 何を実現するかを関係者と決め、要件の整合性と決定経緯を管理する |
| 利用者 | 社内SE、ITコンサルタント、要件定義担当のSE・PM、インフラ・ネットワーク担当、調整担当 |
| 入力 | 資料、録画、議事録、人の判断 |
| 出力 | 根拠付きの要件、確認資料、要件定義書、変更の経緯、回答 |

## 守るルール

| ルール | 実装 |
|---|---|
| AIの出力だけで要件や合意を確定しない | 候補として保存。合意は `actor_kind="human"` のみ |
| 作成・発言・送付では合意にならない | 状態は判断の記録でのみ変更 |
| 受付だけで要件を変更しない | 合意済みの判断を関連付けて反映 |
| 古い合意を自動で引き継がない | 変更すると確認待ちへ戻す |
| 数値・ポート・担当者・期限を創作しない | AIへの指示、入力にない数値の検出、未設定の表示 |
| 理由がなければそう答える | 「理由の記録がありません」 |
| 未検出を保証としない | 調査範囲と未調査の領域を表示 |
| 不明な日付を記録日時で代用しない | 日付の項目を分離 |
| 内部メモを社外資料へ自動掲載しない | 既定で除外、AIにも送らない |

未完成の項目は [残件](残件.md) に記録しています。
